Cómo funciona

El agente propone. Una persona decide.

Karin Triage ordena el trabajo previo para que tu criterio llegue antes a lo importante. No resuelve, no notifica, no sanciona y no cierra casos.

  1. {{ icono('documento', 'landing-paso-icono') }}

    Ingresa la denuncia

    Registras el caso con los datos del relato. Este prototipo opera solo con casos sintéticos.

  2. {{ icono('candado', 'landing-paso-icono') }}

    Se protege la identidad

    Los nombres y datos identificatorios se seudonimizan antes de que el modelo lea el texto.

  3. {{ icono('balanza', 'landing-paso-icono') }}

    Reglas y propuesta

    Reglas deterministas revisan competencia, plazos y riesgos. El modelo sugiere una pre-clasificación con citas literales de la denuncia y de la norma.

  4. {{ icono('validar', 'landing-paso-icono') }}

    Una persona decide

    Revisas, corriges o validas. Los descartes y las excepciones pasan por supervisión.

  • {{ icono('cita', 'landing-garantia-icono') }}

    Citas literales o nada

    Una cita que no aparece tal cual invalida la propuesta.

  • {{ icono('alerta', 'landing-garantia-icono') }}

    La urgencia solo sube

    Las reglas pueden elevarla, nunca bajarla.

  • {{ icono('escudo', 'landing-garantia-icono') }}

    Nadie se descarta por falta de prueba

    Un descarte exige un motivo del catálogo y una cita que lo respalde.
